# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the work.
Harassment, personal attacks, and discriminatory language are not welcome.

Report unacceptable behaviour to the maintainer via a
[private security advisory](https://github.com/Jasviers/actions/security/advisories/new)
or by email. Reports are handled confidentially.
